# 好書研究所 by AJ Studio 獨立書庫與財經實驗室 (v1.8)

本版本為「好書研究所 by AJ Studio」獨立公開網站（**v1.8 財經投資專欄與實戰實驗室升級版**），以「一書一檔」模組化書庫架構為核心，並搭載獨立財經專欄與五大互動投資理財小程式。

## v1.8 核心更新

1. **合規化處理（去除了在世名家／評論員實名）**：
   - 所有財經專欄僅引用已出版經典名著、公開歷史統計數據及市場理論（如《波浪理論》、《聰明的投資者》、《反脆弱》、《掌握市場週期》、《富爸爸，窮爸爸》等），避免直接引用在世市場人士名稱所帶來的版權或合規風險。
2. **波浪理論加入「目前恒指位置與未來高低位推演」**：
   - 結合恒指最新 52 週波幅（22,518 – 28,056 點）與 24,000 點整固位置，列出「第 4 浪完結上試 26,200–28,000 點」與「失守支持進入 C 浪探 21,200–21,800 點」雙劇本關鍵位。
3. **新增「工具 5：100萬買入 0941 中移動 ＋ 每年股息再投資高息 ETF 雪球模擬器」**：
   - 模擬一筆過資金配置 0941.HK（預設 6.7% 股息率）後，每年把所收股息自動投入 3110.HK / 3070.HK / 3416.HK 等香港高息 ETF 滾存複利 3–25 年的總資產與被動月入變化。
